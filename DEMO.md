# Демонстрация UltraRezina

## Запуск приложения
```bash
cd /Users/acti0n/Documents/RIP
docker compose up -d  # Поднять MinIO, PostgreSQL, Redis
go run main.go        # Запустить сервер на :8080
```



### 1. Дизайн в Figma
- 3 экрана: каталог, расчёт, детальная страница
- Стиль вдохновлён Apple: мягкие тени, большие радиусы, нейтральные серые
- Источник указан в `static/css/styles.css` (комментарии вверху)

### 2. Приложение повторяет макеты
- Градиентный фон, тёмные карточки, красные CTA
- Одинаковые отступы, радиусы, тени

### 3. Network запросы (3 GET)
1. **Поиск/фильтр**: `GET /api/services?q=ultra&requestId=1`
   - Параметры: `q` (фильтр), `requestId` (ид заявки)
2. **Добавление в корзину**: `GET /api/add?requestId=1&serviceId=28`
   - Параметры: `requestId`, `serviceId`
3. **Расчёт**: `GET /api/calc?requestId=1&mass=100&frequency=50`
   - Параметры: `requestId`, `mass`, `frequency`

### 4. HTML из Response
- `id` заявки: в параметре `requestId`
- Количество в корзине: через `/api/cart`
- URL изображений из MinIO: `http://localhost:9000/images/ultra-rezina.jpg`

### 5. URL MinIO в коде
- Коллекция услуг: `main.go:39-63` (функция `newStore`)
- Использование в шаблонах:
  - `catalog.html` - список карточек
  - `detail.html` - изображение товара
  - `calc.html` - результаты с привязкой к услуге

### 6. Роутинг (3 URL + контроллеры)
- `GET /` → `handleCatalog` (каталог с поиском)
- `GET /calc` → `handleCalc` (страница расчёта)  
- `GET /detail/{id}` → `handleDetail` (детальная страница)

### 7. Фильтрация/поиск
- Реализация: `main.go:148-165` (функция `apiServices`)
- Фильтрует по подстроке в названии услуги
- Параметр `q` передаётся в URL

## Демо-сценарий
1. Откройте `http://localhost:8080`
2. Введите "ultra" в поиск → Network покажет GET с фильтром
3. Нажмите "Купить" у карточки → Network покажет добавление в корзину
4. Перейдите в "Рассчёт" → введите массу и частоту → нажмите "Рассчитать" → Network покажет расчёт
5. Результатов будет столько, сколько товаров в корзине
