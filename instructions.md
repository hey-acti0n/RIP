Информация о проекте: я разрабатываю веб приложения для рассчёта виброизляции различных материалов. При этом приложение похоже на интернет магазин.

База данных: База данных состоит из 4 таблиц. 
calculations
materials
material-calculation
users

Картинки для моего веб приложения храняться в объекттном хранилище Minio.

Весь бэкенд приложения написан на GO.
